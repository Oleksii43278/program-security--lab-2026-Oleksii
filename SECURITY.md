# Security Policy — TaleSpire GM Logger & GM Hub

## Supported Versions
| Component | Supported Version | Distribution |
|---|---|---|
| TaleSpire GM Tools (`tools/gm_hub`, `tools/release`) | `1.0.x` | GitHub Releases (`gm-tools-v*`) |
| Older versions | Not supported | Please upgrade |

## Reporting a Vulnerability
Please do not disclose security vulnerabilities in public issues.
1. Use GitHub **Security -> Advisories -> Report a vulnerability** in this repository.
2. Include the affected component, version, reproduction steps, and impact (without real secrets or tokens).

## Response Targets
- Acknowledgement: within 7 days
- Triage and severity assessment: within 14 days
- Security fix for Critical/High issues: within 30 days
