# Бізнес-логіка TaleSpire GM Logger

## Сутності (Entities) та інваріанти

| Сутність | Поля | Інваріанти |
| :--- | :--- | :--- |
| `LogEntry` | `timestamp`, `event_text`, `previous_hash`, `hash` | - `timestamp` фіксується у форматі ISO 8601 і є незмінним після створення.<br>- `event_text` не може бути порожнім.<br>- `hash` обчислюється один раз при створенні об'єкта. |

## Ключовий алгоритм (Hash Chain)
1. При ініціалізації нового запису система читає останній об'єкт із файлу журналу.
2. Якщо файл порожній (перший запис), поле `previous_hash` отримує значення `genesis`.
3. Якщо файл містить записи, поле `previous_hash` отримує значення `hash` останнього запису.
4. Поточний `hash` обчислюється як SHA-256 від конкатенації: `timestamp` + `event_text` + `previous_hash`.
5. Зміна будь-якого поля постфактум неминуче зламає криптографічний ланцюг для всіх наступних записів.
