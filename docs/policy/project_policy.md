# Політика проєкту — TaleSpire GM Logger

## 1. Скоуп та технології
Ця політика поширюється на вихідний код логера та правила ведення репозиторію.
* **Технології:** Python 3 (стандартна бібліотека).
* **Свідомі обмеження:** Жодних зовнішніх залежностей (вимога для максимальної переносимості інструменту).

## 2. Фундаментальні принципи
* **Append-only:** Застосунок принципово не містить функцій редагування або видалення попередніх записів. Логіка мутацій заборонена.
* **Сліпе хешування:** Система завжди хешує рівно те, що отримала на вхід, без "розумного" форматування тексту, щоб уникнути розбіжностей при валідації.

## 3. Git Workflow та повідомлення комітів
Обов'язкове використання префіксів для всіх повідомлень комітів. Зміни фіксуються дрібними логічними порціями.

| Префікс | Призначення |
| :--- | :--- |
| `[INIT]` | Первинна ініціалізація репозиторію. |
| `[DOCS]` | Створення або зміна проєктної документації. |
| `[SEC]` | Документи безпеки, моделі загроз. |
| `[FEAT]` | Додавання нової функціональності в код. |

## 4. Анти-патерни
* **Обхід ланцюга:** Обчислення хешу без включення `previous_hash` (порушує саму суть системи).
* **Мережеві виклики:** Використання будь-яких модулів для передачі даних назовні (порушує вимогу NFR-01).
