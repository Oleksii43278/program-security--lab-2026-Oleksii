# Глосарій

* **GM (Game Master)** — ведучий настільної рольової гри, єдиний користувач системи.
* **Запис (Log Entry)** — атомарна структура даних, що містить мітку часу, текст події та криптографічний підпис.
* **Хеш-ланцюг (Hash Chain)** — метод зв'язування записів, де криптографічний хеш поточного запису обчислюється на основі його даних та хешу попереднього запису.
* **SHA-256** — криптографічна хеш-функція, що використовується для генерації підписів записів.
* **Tampering** — загроза несанкціонованої модифікації даних.
* **Repudiation** — загроза відмови від здійсненої дії.
