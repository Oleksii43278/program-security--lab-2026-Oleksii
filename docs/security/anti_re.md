# Протидія реверсивній інженерії (TaleSpire GM Logger)

## 1. Аналіз клієнтської частини
- **Клієнтські компоненти:** скрипти Python (`main.py`, модулі логування TaleSpire GM Logger) та локальна перевірка автентичності релізів відкритими ключами (`release_signing.pub`, `release_passport.pub`).
- **Вразливі місця до реверс-аналізу:** відкриті рядкові константи, умови локальних перевірок (`if/else`), імена функцій та змінних у вихідному коді й байткоді `.pyc`, налагоджувальні повідомлення.

## 2. Прийняті методи протидії
- **Архітектурний захист (відсутність секретів у клієнті):** закриті ключі (`drs_release.signing.key`, `release_passport.key`) та база облікових записів зберігаються виключно у середовищі супроводжувача поза клієнтською поставкою.
- **Гігієна релізу:** виключення службових файлів, кешів `__pycache__`, секретів та абсолютних шляхів із релізного пакета.
- **Ускладнення контрольних перевірок:** комбінація лексичної обфускації, приховування констант, сплощення потоку керування, непрозорих предикатів, сміттєвого коду та непрямого порівняння SHA-256 (`hmac.compare_digest`).

## 3. Свідомо відхилені методи
- **Динамічне виконання коду (`exec`/`eval`) та агресивне антиналагодження:** створюють ризик ін'єкції коду, нестабільної роботи та хибних спрацювань антивірусів, що суперечить відкритій моделі Freeware / MIT.
