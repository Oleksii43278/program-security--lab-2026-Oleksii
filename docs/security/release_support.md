# Підготовка до релізу та довгострокова підтримка (TaleSpire GM Tools)

## 1. Склад релізу та перевірка готовності
- **Релізний продукт:** пакет інструментів `talespire-gm-tools` (`tools/gm_hub`, `tools/release`, документація безпеки), версія **1.0.0**, тег **`gm-tools-v1.0.0`**.
- **Автоматична перевірка (`tools/release/release_tools.py check --osv`):** чистота Git, відсутність секретів і заборонених файлів, безпечні робочі налаштування (TLS 1.2+, `127.0.0.1`, TTL 600 с), фіксація залежностей (`requirements.txt`), перевірка вразливостей у базі **OSV**, проходження самоперевірок `gm_hub` (28/28 OK) і DR (6/6 OK), відтворюваність складання.
- **Артефакти:** детермінований архів `.zip` (з внутрішнім `MANIFEST.sha256`), перелік компонентів SBOM **CycloneDX 1.5** (`.cdx.json`) та файл контрольних сум `SHA256SUMS.txt`.

## 2. Порядок довгострокової підтримки
- **Моніторинг вразливостей:** прийом повідомлень через приватні Security Advisories на GitHub (деталі в `SECURITY.md`), щомісячна перевірка залежностей через `release_tools.py check --osv`.
- **Оновлення:** фікс у коді → автотести → `check --osv` → позачергова резервна копія `pre-update` → збірка нового тегу й артефактів → розгортання та перевірка `/api/v1/ledger/verify`.
- **Відкат після невдалого оновлення:** зупинка сервера → `git checkout` попереднього тегу → відновлення даних із копії `pre-update` → перевірка хеш-ланцюга та працездатності.
- **Підтримувані версії:** актуальна гілка `1.0.x`; після виходу нової MINOR-версії попередня отримує виправлення безпеки протягом 3 місяців.
- **Завершення підтримки (EOL):** публічне оголошення не менш ніж за 30 днів → фінальний реліз і резервна копія → відкликання токенів і клієнтів, знищення закритих ключів TLS та E2EE, безпечне видалення робочих даних та архівування репозиторію.
